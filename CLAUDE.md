# The World of SPLectrum — index to the rules

The site is a Jekyll site under `docs/` (live at https://splectrum.world). This file only points to where the rules live; the files themselves are authoritative. Where two pages or rules disagree, the more recent version wins by default (`process/organic-ecosystem.md`).

## How we work

- `process/working-rules.md` — commits (only on Jules's word, everything pending, to `main`), never deleting without instruction, discussion before drafting, standalone working docs, blocked sources, reserved words, absolute links.
- `process/page-done.md` — front matter, review, ripple, commit; who decides and who applies what; sweeps.
- `process/organic-ecosystem.md` — docs follow practice; keeping the repo consistent with a new rule is Claude's job.
- `process/equal-standing-collaborator.md`, `process/pushback.md`, `process/one-thing-at-a-time.md`, `process/transitional-frictions.md` — the collaboration.
- `process/drafted-posts.md` — drafted posts are Jules's call.
- `process/working-notes.md` — where notes live (`submissions/`, `plan/`) and their marks.
- `process/memory-maturation.md` — working rules go into the repo in the same session.
- `process/remove-completed.md` — finished items leave the planning files.
- `scheduled-tasks.md` — plan work and research tracking; the only linking layer between working docs.

## Voice and pages

- `tone-of-voice/tone-of-voice.md` — the master: registers, the seed pages (principles side only).
- `tone-of-voice/positioning-section.md` — persons, subjects, meta subjects, rings, wider landscape; link direction; closers; safe writing.
- `tone-of-voice/bottom-row-section.md` — Language, Vocabulary, Tools.
- `tone-of-voice/post-vs-ref-lib.md` — posts against reference pages.
- `tone-of-voice/standards.md` — quality rubric and SEO.
- `process/page-structure.md`, `process/keyword-doorways.md`, `process/backing-flows-down.md`, `process/a-z-structure.md` — page structure and building.

## Publishing

- `posting-guide.md` — posts (template, cadence, labels, status, tweets) and `./publish.sh` (check, preview, deploy; deploy on a post's publication day).
- `process/local-jekyll.md` — the local dev server (Docker, localhost:4000).
- `process/check-before-commit.md` — check rendering changes in the browser.

## Agents

- `.claude/agents/reviewer.md` — read-only page review.
- `.claude/agents/researcher.md` — fact checks and research notes.
