# The Paradigm Cases of Emergence

Every definition in [the types catalogue](/positioning/subjects/e/emergence/the-types/) was built on a case — the example its founding text works through and returns to. This page tabulates the pairings, each checkable against the founding paper or book. The field's own literature names the reason such a table is worth having: Humphreys' handbook chapter observes that, unlike causation, emergence has no agreed set of core examples against which accounts can be tested, and suggests assembling candidate examples as a useful project.

## The definitions and their cases

| Definition | Built on |
|---|---|
| Heteropathic effects ([Mill](https://en.wikipedia.org/wiki/John_Stuart_Mill)) | Chemical combination — the properties of compounds against those of their elements |
| Emergent vs resultant ([Lewes](https://en.wikipedia.org/wiki/George_Henry_Lewes)) | Chemical combination, against mechanics' composable forces |
| Emergent qualities ([Alexander](https://en.wikipedia.org/wiki/Samuel_Alexander)) | The ladder space-time → matter → life → mind → deity — deity his own next emergent, and the book's title — with mind the working case |
| Emergent evolution ([Morgan](https://en.wikipedia.org/wiki/C._Lloyd_Morgan)) | Life and mind arising in evolutionary sequence |
| British emergentism ([Broad](/positioning/persons/b/broad/)) | Chemistry — the properties of compounds as his confident example, carried with its contested reception on his page — with mind the book's larger business |
| Emergent interactionism ([Sperry](https://en.wikipedia.org/wiki/Roger_Wolcott_Sperry)) | Consciousness and the split-brain results |
| Two senses ([Searle](/positioning/persons/s/searle/)) | Liquidity and solidity of water; consciousness as the accepted sense's case |
| Weak emergence ([Bedau](/positioning/persons/b/bedau/)) | Conway's Game of Life and [artificial-life simulations](/positioning/subjects/c/complex-adaptive-systems/) |
| Nominal emergence ([Bedau](/positioning/persons/b/bedau/)) | Macro-properties generally — the contrast class for the other two |
| Weak/strong cut ([Chalmers](/positioning/persons/c/chalmers/)) | Consciousness as the sole serious strong candidate; Game-of-Life-style patterns as the weak examples |
| Weak/strong metaphysical ([Wilson](/positioning/persons/w/wilson-jm/)) | The book's worked set: special-science entities, complex systems, artifacts, free agency, consciousness — cases spanning all three of the mechanism page's groups |
| Formalised for critique ([Kim](/positioning/persons/k/kim/)) | Mental causation — the mind-body debate's standing case |
| Non-structural properties ([O'Connor](https://en.wikipedia.org/wiki/Timothy_O%27Connor_(philosopher))) | Mental properties and agency |
| Failure of aggregativity ([Wimsatt](https://en.wikipedia.org/wiki/William_C._Wimsatt)) | The philosophy of biology's cases — organismal traits against aggregable properties like mass |
| Fusion ([Humphreys](https://en.wikipedia.org/wiki/Paul_Humphreys_(philosopher))) | [Quantum entanglement](/positioning/subjects/r/relational-quantum-mechanics/), with covalent bonding as the chemistry case |
| Transformational ([Guay & Sartenaer](https://philpapers.org/rec/GUAANL)) | The fractional quantum Hall effect — long treated as a paradigmatic emergence case |
| Contextual ([Bishop & Atmanspacher](http://www.scholarpedia.org/article/Contextual_emergence)) | Temperature — thermal equilibrium from mechanics — extended to mental states from neurodynamics |
| Causal emergence ([Hoel](https://www.pnas.org/doi/10.1073/pnas.1314922110)) | Simple causal-model systems (boolean networks), motivated by neuroscience |
| Asymptotic ([Batterman](https://en.wikipedia.org/wiki/Robert_Batterman)) | [Critical phenomena](/positioning/subjects/p/phase-transitions/) and the rainbow — the singular-limit cases |
| Level-autonomy ([Anderson](/positioning/persons/a/anderson/)) | The ammonia-molecule inversion — the essay's own worked example — then [broken symmetry at scale](/positioning/subjects/p/phase-transitions/): antiferromagnets, superconductivity |
| Protectorates ([Laughlin & Pines](https://www.pnas.org/doi/10.1073/pnas.97.1.28)) | The quantum Hall effect and [superconductivity](/positioning/subjects/p/phase-transitions/) |
| Complexity working definition ([Goldstein](https://en.wikipedia.org/wiki/Jeffrey_Goldstein_(academic))) | The complexity standards — [Bénard cells](/positioning/persons/p/prigogine/), the Game of Life |
| Intrinsic ([Crutchfield](https://en.wikipedia.org/wiki/James_P._Crutchfield)) | [Cellular automata](/positioning/persons/w/wolfram/) and dynamical systems read through ε-machines |
| Multiscale variety ([Bar-Yam](https://en.wikipedia.org/wiki/Yaneer_Bar-Yam)) | The parity-bit string — a constraint visible only at whole-system scale |
| Three orders ([Deacon](https://en.wikipedia.org/wiki/Terrence_Deacon)) | Snowflakes and [Bénard cells](/positioning/persons/p/prigogine/) for the middle order; life and mind for the third |
| Top-down classes ([Ellis](https://en.wikipedia.org/wiki/George_F._R._Ellis)) | The digital computer as the exemplar, with biological cases alongside |
| Emergence vs self-organisation ([De Wolf & Holvoet](https://link.springer.com/chapter/10.1007/11494676_1)) | [Multi-agent engineering cases](/positioning/subjects/c/complex-adaptive-systems/) — traffic, swarms |
| Social emergence ([Durkheim](/positioning/persons/d/durkheim/); [Sawyer](https://en.wikipedia.org/wiki/R._Keith_Sawyer)) | Suicide rates and religion; improvised conversation (Sawyer) |
| Spontaneous order ([Hayek](/positioning/persons/h/hayek/)) | Market prices |
| Emergent abilities ([Wei et al.](https://arxiv.org/abs/2206.07682)) | Benchmark tasks — multi-digit arithmetic, word unscrambling — across model scales |
| The taxonomies ([Van Gulick](https://en.wikipedia.org/wiki/Robert_Van_Gulick); [Stephan](https://philpapers.org/rec/STEVOE); [Fromm](https://arxiv.org/abs/nlin/0506028)) | Built on the literature itself rather than a single case — instruments for sorting the others |

## What the pairing shows

Chemistry founded the tradition — Mill, Lewes and Broad all built on chemical combination — and chemistry is also where the tradition's central reversal happened, which is part of why the case recurs in every later history. Consciousness anchors the definitions on which underivability is ultimate: Sperry, Chalmers, O'Connor and the mind-directed side of Kim's target all build on the mental case, and it is the one founding case that has not migrated between groups. And the definitions with formal or operational statements were built on cases that can be run or measured — simulations, spin systems, benchmark curves, model networks — where the definition's precision and its case's tractability arrive together.
