# P1 Language Is Relational 101

**P1 — Language is relational.**

This principle is quite simple: language always expresses relations between things. The linguist [Saussure](/positioning/persons/s/saussure/) put it sharply, a century ago: in language there are only differences. In the principles, language means any language, not only spoken and written ones. Words are simply the easiest place to see it.

A word on its own means nothing. *Up* only makes sense against *down*, and against a body that stands upright. *Heavy* is heavy because there is *light*. Think of a chess knight: carved wood, nothing knightly in it. What makes it a knight is how it moves among the other pieces.

What does language relate? Concepts. And a concept is not only an abstract idea: *dog* is one as much as *justice*. A concept is a bag of relations with a label on it: this dog, that dog, a bark in the night, gathered under one name. Language is what relates these bags to each other: relations within, relations between.

This takes us back to the first principle. To be is to stand apart from your surroundings, and standing apart means differing: differences are relations.
