# Third Party Software

Software maintained by others, as it comes from upstream. This section documents it as a reference: what each piece is, where it lives upstream, and how the parts fit together.

## Holepunch
- [Bare](/engineering/third-party-software/bare/) — the minimal JavaScript runtime the stack targets, its module ecosystem, and how you port code to it.
- [P2P building blocks](/engineering/third-party-software/p2p/) — the Hypercore family plus the networking, crypto, and availability layers. Usable directly, independent of Pear.
- [Pear](/engineering/third-party-software/pear/) — the peer-to-peer runtime and deployment platform: the runtime as an embeddable library, the CLI for deployment and installation.

## Other Software

- [Docker](/engineering/third-party-software/docker/) — the containers the swarm's nodes run in.
- [isomorphic-git](/engineering/third-party-software/isomorphic-git/) — pure-JavaScript git, with pako for zlib, under Mycelium's git.
- [React and htm](/engineering/third-party-software/react-and-htm/) — Splectral's browser shell, without a build step.
