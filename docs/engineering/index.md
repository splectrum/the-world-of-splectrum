# Engineering

Engineering here is built for AI autonomy: AI is not a helper outside the system but its principal user, and is to be a working part of the platform across the whole lifecycle. The work is organised in four planes: management (HAICC), the data repository and processing (both built on Mycelium), and interaction (SPLectral).

What is being built now is a family of self-contained packages, **base**, the first concept build. It is partway through a move to strict schema contracts, one package at a time. The detail is kept with the code, in the documentation packages, which change as the work goes on; the way in is [base-docs-haicc](https://github.com/haiccing/base-docs-haicc).
