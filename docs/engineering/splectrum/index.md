## The three pillars

- [Mycelium](/engineering/mycelium/) — the data fabric, substrate architecture. The ground.
- [SPLectrum](/engineering/spl/platform/splectrum/) — the language fabric. Metadata on the data fabric. Identifier grammar, protocols, personas.
