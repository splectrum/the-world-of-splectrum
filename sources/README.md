# Sources — local reference library

Third-party documents kept for reading and source checking: papers, essays, book chapters. **The files themselves are not in the repository** — the folder is ignored by git, because the documents remain under their authors' copyright and the repository is public. Only this index is committed. To rebuild the folder on another machine, fetch each document from the source given.

Add an entry here whenever a document is added to the folder: file, title, author, year, and where it came from.

## FQXi essay contest 2017 — Wandering Towards a Goal

The original contest essays of the prize winners (contest theme: "Wandering Towards a Goal: How can mindless mathematical laws give rise to aims and intention?", FQXi, 2016–2017). Downloaded 2026-10-11 from the essay PDFs linked in each entry's discussion thread on forums.fqxi.org (entry pages at qspace.fqxi.org/competitions/winners/13).

Enhanced versions were published as Aguirre, Foster and Merali (eds.), *Wandering Towards a Goal*, The Frontiers Collection, Springer, 2018 (DOI 10.1007/978-3-319-75726-1). Cite the published chapter where it differs from the contest version.
